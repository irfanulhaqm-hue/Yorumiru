# Yorumiru V4.2.1 — Premium visual patch

This is a visual refinement of the working V4.2 build. Core behavior and the existing
localStorage key (`yorumiru-v4`) are preserved.

## Design
- Stronger premium dark navy/charcoal foundation
- Violet as the primary brand accent
- Teal reserved for active/progress/success states
- More restrained gradients and glow
- Editorial card proportions and cleaner spacing
- Stronger visual hierarchy and typography
- Refined search, genre chips, tabs, watchlist rows and profile
- More polished anime detail and episode surfaces
- Softer glass navigation with clearer active state
- Better mobile spacing and touch targets
- Cache-busted asset versions (`421`) to make deployment changes visible

## Important
Do not delete the repository or local data. Replace the files in the existing
Yorumiru repository and commit them to `main`.
