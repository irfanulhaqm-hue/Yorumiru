YOROMIRU v4.5 — FULL VISUAL PATCH

This patch keeps the existing tracking/data functionality and replaces the visual system.

Major changes:
- New Obsidian / Signal visual language: charcoal, warm amber, ice-cyan.
- Replaced text-style navigation symbols with consistent inline SVG icons.
- New header/brand treatment and search control.
- New Explore hierarchy: cinematic spotlight + horizontal discovery rails.
- Shuffle controls redesigned and retained for discovery rails.
- New card geometry: tighter corners, clearer hierarchy, less visual clutter.
- Profile redesigned with a proper banner area and larger square profile portrait frame.
- Banner/avatar edit controls use standard line icons.
- Watchlist, Upcoming, collection cards and episode dialogs updated to the same design system.
- Dialogs, favorites, character picker and banner picker restyled for consistency.
- Mobile spacing and bottom navigation adjusted for smaller screens.
- Local data key migrated to yorumiru-v4.5 while retaining fallback reads from earlier Yorumiru versions.
- Existing anime data still comes from AniList and episode detail loading still uses Jikan.

Deploy:
Upload index.html, app.js and styles.css to the same GitHub Pages folder.
If GitHub Pages shows an old style, hard-refresh once because the asset query version changed to v450.
