# Yorumiru

Personal offline anime watch tracker for Android.

## Current version
- Anime-only
- Seasons + episodes
- Tap episodes to mark watched
- Automatic progress
- Mark/unmark all episodes in a season
- Local-only storage
- Dark anime-focused UI

## Open/build
Open this folder in Android Studio and let Gradle sync. Then run it on an Android phone or emulator.

This is deliberately a small V1. Posters, reordering, backups, search and richer anime metadata can be added later.
