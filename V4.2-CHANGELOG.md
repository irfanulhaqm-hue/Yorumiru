# Yorumiru V4.2 — Design Polish Patch

V4.2 is a visual/UX polish patch on top of V4.1. Existing local data and core functionality are preserved.

## Design changes
- Refined dark blue-black foundation
- Restrained teal + violet accent system
- More consistent cards, borders, radii and spacing
- Cleaner typography hierarchy
- Softer glass-like sticky header and bottom navigation
- More premium anime cards with subtle hover treatment
- Improved profile hero and stat cards
- Refined anime detail, season and episode surfaces
- More restrained buttons and chips
- Better mobile spacing and desktop navigation behavior
- Reduced visual noise and excessive neon treatment

## Preserved
- Discover/search/genre filtering
- Watchlist and upcoming tabs
- Profile and local account details
- Anime detail modal
- Seasons and episode progress
- Episode bulk-progress confirmation
- Favorites and character favorites
- LocalStorage data key: `yorumiru-v4`
